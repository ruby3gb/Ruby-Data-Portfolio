# Ruby-Data-Portfolio

Crab_Analysis_Data and Crab_Analysis_R
    The Crab Analysis data was collected from 3 different islands off of the coast of Loreto, Mexico. The R script was written with the help of Claude Chat Bot to analyze the behaviors of the crabs towards bait presented with and without a foreign object. The purpose of the experiment was to see if crab feeding behavior changes when foreign objects are around, giving insight into how crab behavior may evolve as their habitats are increasingly exposed to human pollutants.
